GameLib Log: 2026

10/21/2026

Quite a few additions added/redone from the rewrite in order to support ZfxHops and a demo I made for the CNY Game Developers meetup on 10/8/2026:

  • MD2 3D animated models
  • Basic music/sound effects using SDL2_mixer
  • IQM 3D skeletal animation
  • Updated PS3 FNT Font implementation based on hardware testing issues
  • Consolidated PS3 endian swap functions to EndianSwap.h
  • GitLab docker image for ci/cd and ease of building/testing
  • mkdocs/mkdoxy documentation (available online here)

The latest code is available on gitlab now here: https://gitlab.com/HopsLib/HopsLib.

The demo is in its own repo: https://gitlab.com/hopslib/cnygamedevdemo10082026.
